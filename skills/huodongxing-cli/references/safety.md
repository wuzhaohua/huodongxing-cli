# 写操作与隐私安全

## 三阶段

1. **读取**：刷新目标对象，确认当前状态。
2. **计划**：运行 `action-plan`，展示对象、范围、字段、费用、可逆性和验证方式。
3. **提交**：只在用户对该次具体动作明确确认后，通过真实浏览器执行；完成后回读。

## 必须确认

- 免费或付费报名，因为都会提交个人资料。
- 发布、编辑、复制、删除活动，改变公开/私密状态。
- 邀请、短信、邮件、评价回复、群发或任何外部触达。
- 审核、取消资格、退票、退款、签到、拉黑、标签修改。
- 广告、充值、支付、会员、优惠券、票款提领、发票。
- 实名认证、合作签约、收款账户、子账号、权限和安全设置。
- 上传真实海报、名单、证件、合同、二维码或私人截图。

## 只读但敏感

- 参与者名单、手机、邮箱、公司、职位、备注、标签、签到和订单。
- 财务余额、票房、结算、发票和合同状态。

Agent 读取登录态页面时，默认只提取完成任务所需的最少字段，并在对话输出中脱敏常见 PII；不得把完整名单上传或写入 Skill。

## 禁止

- 绕过验证码、登录保护、审核、支付确认或平台风控。
- 回显密码、Cookie、Token、验证码、身份证、支付数据。
- 把“已打开页面”“已点击”“已提交”“待审核”说成“报名成功”。
- 在不清楚范围时群发、批量改名单、删除、退款或签到。
- 根据页面私有请求猜测并固化未授权 API。

## 验收

- 报名：成功页、订单或电子票；审核制标记“待审核”。
- 发布/编辑：活动列表状态 + 公开页回读。
- 消息：发送对象、数量、费用和发送记录。
- 签到/审核/退款：名单或订单状态与时间。
- 支付/提领：订单、余额或流水。
- 删除/隐私：列表和公开页同时验证。

无法取得验收证据时，结果为“未知”，不能报成功。
