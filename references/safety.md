# 写操作、隐私和平台安全

## 七级风险

| 风险 | 例子 | 处理 |
|---|---|---|
| `read` | 公开活动、路由、嵌入代码结构 | 可直接执行 |
| `sensitive-read` | 票券、名单、用户、财务、账号 | 最小读取、默认脱敏 |
| `prepare` | 报名预检、草稿校验、打开创建页 | 可执行但不提交 |
| `commit` | 报名、发布、编辑、审核、签到 | 本次对象明确确认 |
| `paid-commit` | 收费报名、短信、广告、退款、提领 | 金额和对象逐次确认 |
| `destructive-commit` | 删除、取消资格、拉黑 | 说明不可逆性并逐次确认 |
| `security-commit` | 认证、联系方式、权限、子账号 | 身份和权限逐次确认 |

## 三阶段提交

1. **读取**：刷新目标对象，确认身份、状态、票价、范围和权限。
2. **计划**：运行 `signup-plan`、`event-draft plan` 或 `action-plan`，展示影响、个人数据、费用、可逆性和验收。
3. **提交**：只在用户确认本次具体动作，或安全免费报名满足本地预授权时，通过真实浏览器执行；完成后回读。

## 永远逐次确认

- 收费或混合票价报名、支付、充值、广告、会员、短信、优惠、退款、票款提领和发票。
- 实名、证件、意外个人字段、上传名单/附件/合同/二维码。
- 发布、编辑、复制、删除活动和改变公开/私密状态。
- 邀请、群发、评价回复和任何外部触达。
- 名单新增、审核/拒绝、取消资格、退款、签到、备注、标签和拉黑。
- 协作成员、子账号、权限、认证、联系方式和账号安全。

策略文件不得覆盖这些硬边界。

## 只读隐私

- 票券：订单号、二维码、报名资料和联系方式。
- 名单：姓名、手机、邮箱、公司、职位、答案、备注、标签、签到和支付。
- 财务：余额、票房、结算、发票、合同和收款账户。
- 账号：昵称、真实姓名、手机、邮箱、地区和验证状态。

`me-tickets`、`host-events` 和 `browser-read` 默认不输出上述值。确需处理时，只读取任务需要的字段，不写入 Skill、Git、共享经验或公开聊天。

## 平台风控

- 公开详情使用 30 分钟缓存，默认 12 个候选、3 个并发。
- 摘要能判定城市/形式不符时，不再请求详情。
- 验证页、操作过于频繁、403、429、异常登录或验证码触发当批熔断。
- 不通过增加并发、轮换标识、代理、复用验证码或调用私有接口绕过。

## 禁止

- 回显密码、Cookie、Token、Authorization、local storage、验证码、身份证或支付数据。
- 把页面私有网络请求包装成“官方 API”。
- 把打开页面、点击、提交、待审核或草稿称为成功。
- 在对象/范围不清楚时批量群发、退款、删除、签到或改名单。
- 操作用户已有标签页；后台命令只能关闭自己创建的标签页。

## 验收

- 报名：成功页、订单或电子票；审核制标为待审核。
- 发布/编辑：主办方列表状态 + 详情页回读；公开/私密需匿名访问验证。
- 消息：发送对象、数量、费用和发送记录。
- 签到/审核/退款：名单或订单的新状态、时间和流水。
- 支付/提领：订单、余额或流水。
- 删除：后台列表和公开页都验证。

无法取得证据时，结果为“未知”，不能报成功。
