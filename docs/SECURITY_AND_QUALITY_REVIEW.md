# v3.0.0 安全与质量评估

评估日期：2026-07-14。

## 结论

v3.0.0 可作为活动行公开发现、登录态脱敏读取和运营计划控制面。公开命令不需要账号；登录态命令只通过本机 CDP 在 Chrome 内使用会话，不导出浏览器凭据；最终写操作不由 CLI 直接提交。

发布建议：**可发布为 v3.0.0，但必须保留“非官方、浏览器提交、页面易变、真实写操作未自动化验证”的限制说明。**

## 真实平台盘点

使用已登录 Chrome 的独立后台标签页验证了：

- 个人端：我的票券、有效/未完成/取消/退票分类、收藏、个人主页、账户设置；
- 主办方端：仪表盘、活动列表、主页、广告、短信、活动组、邮件素材、用户、咨询评价、发票、票款、充值、子账号和账号管理；
- 单活动：概览、编辑、邀请、推广、渠道码、邀请码、白名单、优惠码、名单、发送记录、签到、协作、结算、网页嵌入和复制；
- 创建页：模板、AI 链接识别、主办方、标题海报、单次/重复时间、地点/直播、详情、嘉宾、票种、报名字段、隐私和售后。

盘点只读取页面结构和动作，不提交报名、发布、退款、群发、签到、支付或账号修改。

## 本次新增实测发现

1. 报名字段 `Subitems` 在真实活动中既可能是对象数组，也可能是字符串数组。v3 兼容两种结构并加入测试。
2. 连续详情请求会跳转到 `verify.huodongxing.com/gt3` 并显示“操作过于频繁”。v3 检测验证页、当批熔断、降低预算并增加 30 分钟公开缓存；不绕过验证码。
3. 活动列表中的“免费”可能是混合票种存在一张免费票。v3 用 `pricing=free|mixed|paid` 表达，免费筛选只保留 `free`。
4. 主办方活动页只展示当前分页。`host-events` 固定返回 `current_page_only=true`，避免夸大全量覆盖。
5. 账户存在套餐/认证限制弹窗。动作存在不代表账号有执行权限；必须以实际页面状态为准。
6. 登录态新标签页也可能被导向频控验证页。v3 会检查最终域名和页面标题，明确返回熔断错误，不再把验证页误判为“未登录”或正常后台。

## 隐私

- Release 不包含 `~/.config/hdx/`、`~/.cache/hdx/`、`.env`、Cookie、Token、订单、名单或用户资料。
- `me-tickets` 不返回订单 ID、二维码或报名值。
- `browser-read` 不返回 hidden input 值、普通表单值、名单行或财务值。
- `host-events` 返回主办方当前页活动运营摘要，标记为敏感读取。
- CDP 代理地址可配置，但默认只连接 `127.0.0.1`；覆盖为远程地址时，必须由使用者确认该代理可信。

## 写操作

`action-plan` 覆盖报名/退票、活动发布/编辑/复制/删除/隐私、名单、消息、签到、营销、协作、支付、提领和账号安全。它返回确认令牌，但 `cli_commits_directly=false`。

原因：活动行普通网页账号没有本项目获授权的稳定写 API；直接固化私有请求会增加账号、资金、隐私和改版风险。最终提交必须在真实 UI 中完成并回读。

## 剩余风险

1. 活动行 HTML、CSS、内嵌变量和后台路由可能随时变化。
2. `mode` 目前根据城市/地址识别 online/offline；平台没有公开混合枚举时不猜测 hybrid。
3. 搜索严格模式在缓存未命中时仍会产生有限详情请求；高频定时任务应错峰并复用缓存。
4. 登录态命令依赖本机 `web-access` CDP 代理；其他机器需要提供等价且可信的代理，远程代理会扩大浏览器控制和元数据暴露面。
5. 页面结构快照不能证明某个按钮可成功执行、当前套餐有权限或账户余额足够。
6. 活动内容来自第三方主办方，CLI 不保证真实性、合规性或商业价值。
7. Windows 可运行 `python hdx.py`，POSIX 包装器 `hdx` 不能直接运行。
8. 真实提交路径没有在自动测试中执行，避免对生产账号、参与者或资金造成副作用。
